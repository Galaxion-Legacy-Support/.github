# Galaxion Legacy Support
Galaxion Legacy Support is Virtual World Research Inc's work group for the virtual-world platforms our Galaxion Heritage platforms replace. We keep maintained copies of Halcyon, OpenSimulator 0.8 and 0.9, Aurora-Sim and WhiteCoreSim. We fix security problems, data loss and backup export for the worlds still on them, while those worlds decide whether, and when, to move. The original authors are credited in each repository's CONTRIBUTORS.md; they are not involved in these copies.

Ready to move?
Are you ready to move from a legacy platform to a platform in the Galaxion ecosystem?
